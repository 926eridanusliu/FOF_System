# FOF 尽调前端

Vue 3 + TypeScript + Element Plus 的尽调工作台，对接同级 `backend/` 中的
FastAPI 服务。业务字段和模板书签来自后端已经采用的第二、第三阶段数据，前端
没有另造业务样例。

## 页面

- `/managers`：管理人列表、搜索和统计；
- `/managers/new`：新建管理人；
- `/managers/:id`：管理人详情、产品和尽调历史；
- `/reports/:id`：多 Tab 报告编辑、动态策略、内嵌表格、图片上传、校验和状态流转；
- `/reports/:id/preview`：创建异步 Word 任务、显示进度，并在浏览器中预览和下载。
- `/fill/:token`：管理人专用资料填写页，只读取和修改令牌限定的一份草稿。

草稿编辑页每 30 秒检查一次未保存修改并自动保存。离开有未保存修改的页面前会
二次确认。报告提交后只读，已提交报告可归档。管理方的单报告填写链接可由公司方单独开启或关闭修改权限。

产品可以配置多个策略；新建报告时可以选择多只产品，系统取产品策略并集自动
展开量化、CTA、债券和期权问题，同时允许内部人员手工补充策略。“市场中性”和
“T0”会展开模板现有的量化问题。宏观对冲目前只有模板勾选项，待业务方提供正式
专属问题后再增加分支。

报告编辑页支持选择 JSON 文件，先显示可识别字段、模板外字段和覆盖冲突，再由
用户确认应用。图片路径不会从 JSON 导入，必须通过上传接口重新上传。

报告预览不会用一个请求等待 10–30 秒：页面先取得任务编号，再轮询
`queued / running / completed / failed` 状态。任务完成后才读取 DOCX 并转换为
在线预览，因此长时间生成不会触发普通 HTTP 请求超时。

## 准入评分卡

报告编辑页新增“准入评分卡”Tab，流程为：

1. 按正式模板逐项录入或复核15个实际得分；
2. 如需辅助测算，可选上传 `.xlsx` 或 `.csv` 净值文件；
3. 保存评分并核对定量、定性、扣分和总分；
4. 点击“生成并下载 Excel”取得独立评分卡。

评分卡不写入 Word，附件1-1、附件1-2和评分卡 Excel 分别下载。

## 历史版本

报告编辑页“版本历史”Tab 会列出每次提交生成的 V1、V2……快照。选择任意两个
版本可以查看字段级差异，包括新增、删除和修改的表单字段及评分结果。

“回滚到此版本”不会修改或删除历史记录，而是把选中版本的表单、评分卡、图片和
净值文件复制为新的当前草稿。再次编辑并提交后，系统会继续生成下一个不可变版本。
如果当前页面有未保存修改，回滚前会明确提示这些修改将被覆盖。

## 本地运行

先启动后端（终端一）：

```bash
cd backend
source .venv/bin/activate
uvicorn app.main:app --reload
```

再启动前端（终端二）：

```bash
cd frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。开发服务器会把 `/api` 和 `/health` 请求代理到
`http://127.0.0.1:8000`。

`npm run preview` 使用的 4173 端口也配置了相同代理，因此本地生产预览不会把
`/api` 请求错误地发送给前端静态服务器。

## 构建与测试

```bash
npm run build
npm test
```

首次或锁文件更新后使用 `npm ci` 严格按照 `package-lock.json` 安装依赖。构建
产物位于 `frontend/dist/`。如将前后端部署到不同域名，请在后端环境变量
`CORS_ORIGINS` 中用英文逗号列出允许的前端地址。
