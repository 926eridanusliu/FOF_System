# FOF 尽调系统用户手册

## 日常流程

1. 打开系统首页，进入“管理人”。
2. 新建管理人并填写真实基础信息。
3. 在管理人详情中新建产品，并勾选每只产品对应的策略。
4. 新建尽调报告，可选择一只或多只产品，并选择正确模板。
5. 按各页签录入信息；图片字段通过上传按钮选择 PNG/JPEG。
6. 保存草稿，处理字段级校验提示。
7. 点击校验，确认必填字段和策略分支均通过。
8. 生成预览。大报告使用异步生成入口，等待完成后下载 Word。
9. 核对报告内容和评分卡，再提交。提交会生成不可变历史版本。
10. 审批完成后归档。

## 邀请管理人填写

1. 内部人员先创建报告草稿。
2. 在报告工具栏点击“管理填写链接”，选择1至30天有效期并生成。
3. 复制新生成的链接，通过公司批准的安全渠道发送给对应管理人。
4. 管理人通过独立页面填写；页面每30秒自动保存，也可以主动保存。
5. 管理人提交后链接锁定。内部人员检查数据、运行校验并生成Word。
6. 如果发错或不再需要，立即在链接列表点击“撤销”。

原始链接只在创建时显示一次。不要把同一链接发给多个管理人，也不要通过公开群聊
发送。生产链接必须为 HTTPS。

## 导入既有 JSON

在草稿报告工具栏点击“导入 JSON”，选择文件后先查看识别字段、忽略字段和冲突。
确认应用只会更新草稿，不会直接提交。管理人名称、关联产品名称和产品自动策略由
系统重新校正；图片仍需单独上传。

## 重要规则

- 草稿可以编辑；已提交和已归档报告不能直接修改。
- 提交前必须通过校验。
- 每次提交形成快照，历史版本不会随当前数据变化。
- 图片只支持 PNG/JPEG，单个文件不超过 10 MB。
- 飞书通知失败不影响 Word 下载；由管理员查看通知状态并重试。
- 不要把客户敏感数据、下载链接或鉴权信息发到公开渠道。

## 删除与恢复

- 管理人详情右上角可以删除管理人，报告编辑页工具栏可以删除报告。
- 删除前必须二次确认并填写原因。
- 删除不会物理清除数据库、历史版本或生成文件，而是从工作台隐藏。
- 左侧“回收站”会显示删除对象、原因和时间；点击“恢复”即可重新显示。
- 删除管理人时，其产品和报告会随管理人一起隐藏；恢复管理人后一起恢复。

## 常见问题

网页打不开：先请管理员检查 `/health`。

生成时间较长：停留在预览页等待任务完成，不要连续重复点击。

通知未收到：报告仍可下载，请把报告编号交给管理员查询通知记录。

Word 内容缺失：不要手工伪造数据，记录报告编号和缺失字段后交给维护人员。
