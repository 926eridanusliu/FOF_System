# 最终演示脚本

1. 打开管理人列表，新建一个演示管理人和产品。
2. 新建私募基金报告，展示多页签、策略动态字段、表格编辑和自动保存。
3. 上传组织架构图和业绩图。
4. 导入/填写净值数据，生成并核对评分卡。
5. 执行字段校验，故意展示一次缺失提示，再补齐。
6. 发起异步生成，展示进度、Word 预览和下载。
7. 查看飞书通知记录；在已配置测试环境确认消息四项内容。
8. 提交报告，展示不可变历史版本。
9. 修改草稿并创建新版本，展示版本差异与回滚。
10. 用附件 1-2 测试数据重复生成，证明模板切换有效。
